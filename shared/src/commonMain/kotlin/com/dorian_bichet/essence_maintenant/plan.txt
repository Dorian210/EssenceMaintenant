Jalon 1 : La Plomberie et les Dépendances (Objectif : Préparer le terrain)
Avant d'écrire du code métier, il faut ajouter les bibliothèques nécessaires dans ton fichier gradle/libs.versions.toml et les build.gradle.kts.

Réseau : Installer Ktor (le client HTTP officiel de Kotlin Multiplatform, l'équivalent de Requests en Python ou Axios en JS).

Parsing : Installer Kotlinx Serialization (pour transformer le JSON/XML du gouvernement en objets Kotlin automatiquement).

Carte : Intégrer un SDK de carte compatible KMP (comme Compose Multiplatform Maps ou MapLibre).
